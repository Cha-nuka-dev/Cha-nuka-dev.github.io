How It Works — Step by Step
01
Pre-Scan Calibration
AgriBot-1 scans the first 4 rows and automatically computes the average maximum and minimum TOF readings — establishing ground level and crop height as the field baseline. No manual setup required.
ground_avg · plant_avg · thresholds locked for entire field run
02
Precise Y-Axis Advance — 2cm per Row
N20 motors drive the robot exactly 2cm forward per row using an AS5600 magnetic wheel encoder. An ultrasonic sensor tracks the side wall gap in real time, auto-correcting steering to maintain a straight path.
~49.8° wheel rotation = 2cm · wall gap target 2cm ±1cm
03
Continuous Fly-By Gantry Scan
The NEMA 17 stepper sweeps the full row width without stopping. The VL53L0X TOF sensor samples height every 80 motor steps — building a complete height profile of every row at speed.
800 steps/s · sample every 80 steps · no stop-start pauses
04
Two-Pass Intelligent Detection
Pass 1 labels every point as ground, weed, or plant using calibrated thresholds. Pass 2 runs an edge artifact filter — discarding any weed candidate within 3 scan steps of a plant boundary, eliminating the false positives caused by the TOF sensor's curved reading profile at plant edges.
ground noise <3mm filtered · edge gap ≤3 steps discarded
05
Targeted Laser or Pump Treatment
Weed mode: laser fires for 5 seconds over each weed centroid. Fertilizer mode: pump delivers to each plant centroid for 3 seconds. Power supplies are fully isolated — preventing motor interference with sensors.
laser 5s/weed · pump 3s/plant · 6V + 12V isolated rails
06
Automatic Field End + Safe Stop
When the ultrasonic sensor detects an ×8 spike in its reading — open air beyond the last row — AgriBot-1 completes its current treatment, then drives exactly 16cm forward to clear the final plant before stopping.
×8 wall spike → finish row → 16cm chassis offset → stop

Detection Algorithm — Core Logic
Calibration Baseline
plant_avg = avg(MIN tof × 4 rows)
ground_avg = avg(MAX tof × 4 rows)
actual_h = ground_avg − plant_avg
Field-wide averages across 4 rows — robust against single-row shadows or soil variation. Computed once, used for all rows.
Weed Classification
oh = ground_avg − tof_reading
isWeed = oh > 3mm
         AND oh < plant_thresh
         AND NOT edge_artifact
3mm noise floor eliminates soil surface bumps. Edge filter removes slope-transition false positives at plant boundaries.
Edge Artifact Filter
plant_thresh = actual_h − 20mm
gap = dist(weed_cluster,
       plant_boundary)
discard if gap ≤ 3 steps
TOF readings curve at plant edges, creating mid-height artifacts that mimic weeds. Two-pass analysis removes these completely.
